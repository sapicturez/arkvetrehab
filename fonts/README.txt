Self-hosted Google Fonts, downloaded 2026-09-14.
Families: Fraunces (normal 400/500/600, italic 400) and Inter Tight (normal 400/500/600).
The WOFF2 files are the same fonts supplied by the original Google Fonts CSS; shared binaries are deduplicated across weights. Unicode subsets remain conditional.
Licenses: fraunces-OFL.txt and intertight-OFL.txt.
Sources: https://fonts.google.com/specimen/Fraunces and https://fonts.google.com/specimen/Inter+Tight
Edit ../fonts.css and run bash scripts/build-assets.sh from the website repository to rebuild the served CSS.
